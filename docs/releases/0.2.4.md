## New

- **Parentheses in unit math.** Group units and use normal precedence: `(3kg + 5lbs) * 2 in oz`, `2 * (1 ft + 6 in) in cm`. A grouped distance over a time gives a speed, such as `(1 mi + 1 km) / 8 min` → 12.16 mph. Weight ounces and fluid ounces never mix. (#190)
- **Daylight-saving answers.** A time that clocks skip, such as 2:30 AM on spring-forward day, now explains the jump and converts the nearest valid time. A time that happens twice when clocks fall back shows one card for each reading, such as EDT and EST. (#191)

## Faster

- **Notes.** Volant keeps only each note's title and preview in memory and loads the full text when you open the note. On a test notebook of 1,000 notes, memory went from about 183 MB to 7 MB. Typing in note search no longer pauses, because full-text matches are found in the background. (#192)
- **Settings icons.** The App Shortcuts list shares the launcher's icon cache instead of fetching icons on every redraw. (#189)

## Fixed

- **Clipboard images.** Copies that carry both an image and text, as many design apps make, now record the image as well as the text. Long text no longer stops the image from being saved. (#180)
- **Your default apps.** Calendar events, meeting links, quicklinks and Open in Dictionary open in the app you chose instead of always using Apple's. (#181)
- **App shortcuts.** A shortcut opens the exact copy of an app you assigned it to, for example a beta next to a release build. (#183)
- **Notes and launcher together.** The window you opened last is in front. Opening Notes during an AI Chat conversation no longer hides behind the launcher. (#184)
- **Dictionary.** Words typed with trailing punctuation or a leading quote, such as `cats.`, return definitions. (#185)
- **Notes shortcuts.** Shortcuts that don't apply right now, such as ⌘E with no note open, no longer make the alert sound. (#187)
- **Helper processes.** Every command Volant runs, including Shortcuts and power settings, gets a fixed, minimal environment. (#182)

## Changed

- `5 km + 300 m * 3` now follows normal precedence and gives 5.9 km. Use parentheses to add first.
- The AI Chat @ note picker matches note titles and previews, plus any open or edited note. It no longer suggests notes that match only in their body.

Requires macOS 15 or later. Apple silicon and Intel.
